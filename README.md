# FindIt

A campus Lost & Found portal for VIT Bhopal students, built for an IEEE hackathon.

## Getting started

You need **Node.js 22.5 or newer**.

```bash
cd backend
node server.js
```

Open http://localhost:3000. Open the site through that address, not by double-clicking the HTML files.
